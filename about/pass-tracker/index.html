Pass Trackerと「参考価値」

ぐるっとパスで何か所か回っていると、私自身、

「このPass、今どのくらい使ったんだろう？」

と思うようになりました。

正確に「いくら得したか」を出したい、というほどではありません。

ただ、

ここまでいろいろ行ったなら、だいたいどのくらいの価値を使ったことになるんだろう。

というのは、ちょっと気になります。

そこで作ったのがPass Trackerです。

訪れた施設を記録すると、その施設で使ったPassの特典をもとに「参考価値」を積み上げて、Passの価格と一緒に見られるようにしています。

これで、

  • 今までどのくらいの参考価値を記録したか
  • Passの価格と比べてどのあたりまで来ているか
  • どこをすでに訪れたか

をざっくり振り返れます。

なぜ「節約額」ではなく「参考価値」なのか

ここは、一番誤解されたくないところです。

Pass Trackerに出ているのは参考価値です。

実際に節約した金額ではありません。

たとえば一般料金1,000円の施設にPassで入った場合、1,000円を参考価値として扱うことがあります。

でも、それは、

「1,000円得をした」

という意味ではありません。

Passがなければ、そもそもそのチケットを買わなかったかもしれません。

逆に、Passがなくても絶対に行っていた人もいます。

「Passがなかったらどうしていたか」は、人によって違います。

だから、この数字が答えようとしているのは、

「これまで使った特典を、確認できる通常料金などを基準にすると、だいたいどのくらいの価値に相当する？」

「実際にいくら節約できた？」

を正確に計算するものではありません。

どんなものを計算するのか

Passで入場できる施設で、対応する一般料金を信頼できる形で確認できる場合は、現在の製品ルールに沿ってその金額を参考にします。

明確な金額の割引なら、確認できた割引額を使います。

ただし、どの施設も同じ条件ではありません。

展覧会によって料金が変わることがあります。

展覧会ごとにPassの条件が違うこともあります。

どの金額を使えばいいのか、十分に確認できないこともあります。

また、現在の製品で「概算」として扱っている値は、あくまで概算として表示します。

数字になったからといって、確認済みの事実になるわけではありません。

「未確認」は0円ではありません

参考価値を信頼できる形で確認できない施設は、「未確認」のまま残ります。

これは、

「この施設は0円の価値しかない」

という意味ではありません。

今の情報では、この特典をひとつの金額にして表すだけの根拠がない

という意味です。

そのため、訪問済み施設すべてが金額として合計に入るとは限りません。

そのほうが、空欄を全部0円にするより正直だと思っています。

どうして全施設に数字を付けないのか

全施設に数字があったほうが、画面はきれいです。

でも、そのために、

  • 適当な展覧会料金を選ぶ
  • 情報がなければ0円にする
  • 根拠のない金額を推測する
  • 施設ごとに違うPass条件を全部同じ式で扱う

ようになると、見た目は完全でも、中身はかえって信用できなくなります。

なのでPass Trackerでは、

信頼できる形で確認できるものだけを計算する。

分からないものは、数字を埋めるためだけに推測しない。

という考え方にしています。

私にとって、これは精密な家計簿ではありません。

「このPass、ここまでどんなふうに使ったっけ？」

と振り返るための目安です。

そして、Trackerの数字を大きくするために、行きたくもない場所へ無理に行ってほしいとも思っていません。

数字を増やすことが目的になったら、少し本末転倒です。

参考価値は、すでに使ったPassの記録を振り返るためのひとつの尺度。

最後にどこへ行きたいかを決めるのは、やっぱり自分だと思っています。

Pass Tracker and “reference value”

After using the Grutto Pass at a few places, I started wondering:

“How much of this Pass have I actually used?”

Not necessarily in the sense of calculating an exact profit.

I was just curious.

After visiting all these places, roughly how much value had I used?

That question eventually became Pass Tracker.

When you record a visited venue, PYOKO adds a reference value based on the Pass benefit used there and shows the accumulated amount alongside the price of the Pass.

It gives you a rough way to look back at:

  • how much reference value has been recorded so far;
  • how that compares with the price of the Pass;
  • which venues you have already visited.

Why “reference value” rather than “money saved”

This is the part I most want to keep clear.

Pass Tracker shows a reference value.

It does not show the exact amount of money you personally saved.

For example, if regular admission to a venue is ¥1,000 and you enter using the Pass, Tracker may use ¥1,000 as the reference value.

But that does not automatically mean:

“You made a ¥1,000 saving.”

Without the Pass, you might not have bought the ticket at all.

Someone else might have visited anyway.

What each person would have done without the Pass is different.

So the number is better understood as answering:

“Using the regular prices or other reliable bases we can confirm, roughly what value do the Pass benefits I have used so far correspond to?”

It is not intended to answer:

“Exactly how much money did I save?”

What gets calculated

When the Pass provides admission and the corresponding regular price can be established reliably, PYOKO uses the appropriate amount under the current product methodology.

When the benefit is a clearly stated fixed discount, the verified discount amount can be used.

But conditions are not identical everywhere.

Prices can change with the exhibition.

Pass conditions can differ between exhibitions.

Sometimes there simply is not enough reliable information to decide which amount should represent the benefit.

And where the current product labels a value as an estimate, it stays an estimate.

Putting an estimate into a total does not magically turn it into a confirmed fact.

“Unverified” does not mean zero

If PYOKO cannot establish a reliable reference value for a venue, that value stays unverified.

It does not mean:

“This venue is worth ¥0.”

It means:

there is not currently enough reliable information to represent this benefit with one specific amount.

That means not every visited venue will necessarily contribute a monetary amount to the total.

I would rather leave something unverified than quietly turn every gap into zero.

Why not just give every venue a number?

It would certainly make the interface look more complete.

But doing that might require:

  • choosing an arbitrary exhibition price;
  • treating missing information as zero;
  • guessing an amount without a reliable source;
  • forcing different Pass conditions through one formula.

The result would look more complete while actually being less trustworthy.

So Pass Tracker follows a simpler idea:

Calculate what can be established reliably.

Do not invent a number simply to fill a gap.

I do not think of it as a precise financial ledger.

It is a way to look back and ask:

“How have I used this Pass so far?”

And I do not want the number itself to become the goal.

If someone starts visiting places they do not even want to see just to make the Tracker number larger, that feels a little backwards.

Reference value is simply one way to compare the Pass benefits you have already used.

Pass Tracker 和“参考价值”

用了几次 ぐるっとパス 之后，我自己也开始想：

“这张 Pass 到底已经用了多少了？”

不是一定要精确算“赚了多少钱”。

只是会有点好奇：

已经去了这么多地方，那大概相当于用了多少价值？

所以后来有了 Pass Tracker。

把去过的设施标记下来之后，PYOKO 会根据在那里使用到的 Pass 权益，累计一个“参考价值”，再把它和 Pass 本身的价格放在一起看。

这样可以大致知道：

  • 目前记录了多少参考价值；
  • 和 Pass 本身的价格相比大概到了哪里；
  • 已经用 Pass 去过哪些地方。

为什么叫“参考价值”，而不是“省了多少钱”

这是我觉得最需要说清楚的一点。

Pass Tracker 显示的是参考价值。

不是你的实际“节省金额”。

比如一个设施普通门票是 1,000 日元，你用了 Pass 入场。

Tracker 有可能把这 1,000 日元作为参考价值。

但这并不代表：

“你真的赚到了 1,000 日元。”

因为如果没有 Pass，你也许根本不会买这张门票。

另一个人可能本来就一定会去。

每个人“如果没有 Pass 会怎么做”的情况都不一样。

所以这个数字更接近：

“把目前已经使用过的这些权益，按照能够确认的通常价格或其他依据来看，大概相当于多少价值？”

而不是：

“我实际省下了多少钱？”

哪些东西会算进去

如果某个设施可以使用 Pass 入场，而且能够比较可靠地确认对应的一般票价，PYOKO 会按照目前的产品规则，把相应金额作为参考依据。

如果权益本身是一个明确金额的折扣，就会使用能够确认的折扣金额。

不过，不同设施的情况真的不完全一样。

有的价格会跟着当前展览变化。

有的展览对应的 Pass 条件也会变化。

有时候虽然知道有优惠，却没办法可靠确认到底应该用哪个金额来代表它。

另外，目前产品里如果某些值只能作为“概算”，也会明确标出来。

概算就是概算，不会因为放进了一个总数里，就突然变成已经确认的事实。

“未确认”不是 0 日元

如果一个设施的参考价值暂时没办法可靠确认，PYOKO 会把它留在“未确认”。

这并不代表：

“这个地方的价值是 0。”

只是代表：

现在没有足够可靠的信息，把这个权益用一个具体金额表示出来。

所以，你已经去过的设施，不一定每一家都会变成一个数字加进总计里。

我觉得这比把空白全部当成 0 更诚实。

为什么不干脆给每一家都算一个数字

当然可以想办法让每个设施旁边都有一个数字。

这样看起来会很完整。

但是如果为了做到这一点，需要：

  • 随便挑一个展览票价；
  • 没有资料就当成 0；
  • 根据感觉猜一个金额；
  • 不管实际 Pass 条件有什么区别，全部套同一个算法，

最后得到的数字虽然更整齐，反而更不可信。

所以 Pass Tracker 的原则比较简单：

能可靠确认的才算。

不能可靠确认的，不为了让数字好看就硬猜。

我把它看成一个回头看看：

“这张 Pass 到目前为止，我是怎么用的？”

的小工具。

不是一份精确的财务结算。

也不是为了鼓励：

“数字越大越好，所以再多跑几家。”

如果为了提高 Tracker 上的数字，反而去了自己根本不想去的地方，那其实有点本末倒置了。

参考价值只是给已经发生的使用记录一个可以比较的尺度。

最后还是那句话：

想去哪，应该由你自己决定。
